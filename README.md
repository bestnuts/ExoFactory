## 설명

**ExoFactory**는 데이터팩과 리소스팩을 중심으로 제작된 마인크래프트 바닐라 콘텐츠이다.  

데이터팩과 리소스팩을 이용한 바닐라 친화적인 구현 방식으로 싱글 및 멀티에서 높은 호환성을 지니고 있다.  

아래는 콘텐츠 목록이다.  

### 테라포밍

- 토지 확장
- 자원 채집

### 공장

- 물품 수송 및 가공
- 전력, 액체, 기체
